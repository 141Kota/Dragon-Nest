# 仕様書（仮称: DragonNest）

## 概要
卵を探して拾い、孵してドラゴンを集める、iPhone向けの短時間プレイゲーム。
家族が隙間時間に遊べることと、作る側が拡張し続けて楽しいことが目的。

## 技術方針
- iPhoneのSafariで動くHTML/JavaScript（フレームワークなし、Canvas描画）
- 縦画面・片手のタップ操作のみ
- 素材は画像ファイルを使わず、すべてコードで描く（ベクター調）
- セーブはlocalStorage（読み込みに失敗しても落ちない作り）
- 公開はGitHub Pages（URLを家族に送って遊んでもらう）
- ホーム画面に追加して使えるようにする（manifest対応）

## 遊びの流れ
1. 場所を選んで探索に出る
2. マップをタップで数マス進み、卵を拾う
3. たまにゴブリンが出て、バトルになる
4. 拠点に戻り、卵を置いて孵化を待つ
5. ドラゴンが孵り、図鑑と拠点が育つ

## 探索
- 場所ごとに雰囲気と出る卵が違う（最初は森・海・火山の3か所）
- 1回の探索は1〜2分で終わる
- 探索に出ると、拠点で孵化中の卵の残り時間が少し縮む
- 場所の追加だけで拡張できるデータ構造にする

## バトル（ゴブリン）
- ゴブリンが卵をつかんで逃げる。画面に逃走ゲージを出す
- ターン制。ゴブリンは次の行動を予告する（突進・ひっかき・盗む構え）
- 行動は「守る・かわす・反撃」から選ぶ。予告に合う行動なら有利
- 行動するたびにゲージが進み、満タンで卵を奪われて失敗
- 3〜4手で決着する。倒せば卵は無事
- 連れているドラゴンの種類とレベルで、使える技と強さが変わる
- ゴブリンは種類を足せる作りにする

## 孵化
- 卵を拠点に置くとリアルタイムで孵る（短め・最長30分程度）。レア卵ほど長い
- 置ける卵は最初は2個
- アプリを開いたときに、時間が過ぎていれば孵化済みにする（通知は使わない）
- 探索とアイテム（ぬくもり石）で残り時間を縮められる
- アイテムは探索とバトルの報酬のみ。課金や広告は入れない

## ドラゴン
- パーツの組み合わせで描く：体型・翼・角・しっぽ・模様・色の6種類
- 各パーツは5種類ほどを用意し、組み合わせで数百体にする
- 全パーツが同じ骨組み（接続点）を共有し、重ねても形がずれないようにする
- 場所ごとに出るパーツの組み合わせを決める（森は緑で翼が小さい、火山は赤で角が大きい等）
- 色違いのレア個体を混ぜる
- 同じドラゴンが再び孵るとレベルが上がる（技が増える・強くなる・見た目が少し変わる）

## 図鑑
- 未発見はシルエット表示
- 場所ごとにページを分け、埋まり具合を表示する
- 見た目を重視する（大きく見やすく、ゆっくり動く）

## 拠点
- 斜め視点の2Dで、奥行きを出す（影・グラデーション・手前と奥の重なり）
- 施設を足すと孵化やバトルが強化される（拡張向け）

## 見た目の方針
- 2Dのベクター調。やわらかい形と色で統一する
- 奥行きは影・グラデーション・重なりで出す
- 文字は日本語。固有名詞も読みやすさを優先する

## 最初の実装範囲
- 場所3か所、ゴブリン2種類、ドラゴンのパーツ各5種類
- 探索・バトル・孵化・図鑑・拠点（施設は2〜3種類）まで一通り遊べる状態
- データ（場所・卵・ゴブリン・パーツ・施設）は1つのデータ定義にまとめ、追加しやすくする

## 決めていないこと
- ゲーム名
- 施設の具体的な種類
- ドラゴンの技の細かい数値（遊びながら調整する）
