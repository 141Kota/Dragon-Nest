# Dragon Nest（ドラゴンの巣）

卵を探して拾い、孵してドラゴンを集める iPhone Safari 向けのゲームです（縦画面・タップとドラッグ）。
仕様は [docs/game_spec.md](docs/game_spec.md)。

## 遊び方
- リポジトリ直下の `index.html` を開くと起動します（GitHub Pages でそのまま公開できます）。
- ローカルで試すときは ES Modules のため HTTP サーバー経由で開いてください（例: `python3 -m http.server`）。
- パソコンでは探索・追跡を矢印キー / WASD でも動かせます。

## 構成
| ファイル | 役割 |
| --- | --- |
| `src/data.js` | **データ定義（場所・卵・ゴブリン・バトル・ドラゴンの系統とパーツ・施設）を1か所に集約** |
| `src/logic.js` | ロジック（孵化・図鑑・チームと得意・バトルの入口と報酬・探索フィールド・ゴブリンの行動）。DOM なし |
| `src/rig.js` | 骨組み描画の共通部品。3Dの骨組みを向き（yaw）に合わせて回して2Dに投影し、部品を奥にあるものから描く。つなぎ目は塗り直して線を消す。細い同系色の線と、光の向き（左上）を全キャラでそろえる |
| `src/dragon.js` | ドラゴン描画（360°）。しっぽの先〜胴〜首〜頭を1本の背骨にし、角・背びれ・翼を背骨の決まった点に接続。息・追従・羽ばたき・系統ごとの歩き方も骨組みから作る |
| `src/figures.js` | プレイヤーとゴブリン（同じ骨組み方式・360°）。立ち・歩き・走り・勝利・失敗の動き |
| `src/battles/*.js` | バトル5種（追跡・罠解除・包囲・防衛・太鼓）。1ファイル1種類 |
| `src/scenes/*.js` | 拠点・探索先えらび・探索・バトルの枠・図鑑 |
| `src/draw.js` / `src/ui.js` | 共通描画（色・文字の自動縮小・折り返し）/ 入力（タップ・スティック・複数の指・スクロール） |

### 入力とスクロール
- スクロールできる画面では、ボタンの上から触ってもドラッグでスクロールできます。指が 8px（`DRAG_PX`）以上動いたらスクロールとして扱い、ボタンの反応は取り消します。
- 縦のパン操作（`touch-action: pan-y` 相当）は `src/ui.js` が自分で扱います。ブラウザに任せると iOS Safari ではドラッグ中に `pointercancel` が来るため、canvas は `touch-action: none` のままにしています。

### 360°の描き方
- ドラゴン・ゴブリン・プレイヤーは骨組みを 3D（X: 前、Y: 左、Z: 上）で持ち、`view(yaw, pitch)` で回して投影します。`yaw` は 0 = 右、π/2 = 奥、-π/2 = 手前。
- `drawDragonAt(..., { yaw })` / `drawGoblin(..., { yaw })` / `drawExplorer(..., yaw)` で向きを渡します（なければ斜め前向き）。探索では移動方向へなめらかに回り、止まると向きを保ち、バトルでは相手の方を向きます。
- 図鑑・拠点など多数が映る画面は `cache` を付けて、絵を小さな画像にして1秒に12回だけ描き直します。小さいものは模様やつやを省いた簡易描画、画面外のものは描きません。

### ゴブリンの行動
- 見回り → 気づく（「！」で短く止まる）→ 追跡 → 見失う（「？」で探す）→ 戻る。`src/logic.js` の `updateGoblins()`。
- 視界は前の扇形と距離（`DATA.goblins[].ai`）。走ると遠くから気づかれ、茂みのそばでは近くまで気づかれません。崖と茂みの向こうは見えません。
- 追跡中に一定の距離を離れるか、崖・川・茂みの向こうへ行くとあきらめます。1体が気づくと近くの仲間も少し遅れて気づきます。
- 気づかれる前に近づくか後ろから触れると、バトルを有利に始められます（足跡に先に気づいた場合も有利）。

### バトルの背景
- 説明カード・バトル中・結果はどれも、探索していたフィールドをそのまま背景に映します（`explore.backdrop()`。暗くする幕は掛けず、カメラだけ少し寄る）。
- 説明カードと結果は画面の下に小さく出し、フィールドとキャラを隠しません。

### 性能
- ドラゴン・ゴブリン・プレイヤーは、向き（16方向）× 動きのコマごとにオフスクリーンへ1回だけ描いて保存し、毎フレームは貼るだけです（`src/sprites.js`）。必要なときに作り、上限を超えたら古いものから捨てます。1フレームで絵を作る時間にも上限があり、超えた分は近いコマや隣の向きで代用します。
- 事前描画のときは動きの速さを1周の整数倍にそろえ、コマがループするようにしています（人型は `POSE_RATE`、ドラゴンは `fq()`）。1体を大きく見せるときは `live: true` でその場で描きます。
- 探索の木・岩・茂みも同じ仕組みで保存し、空・霧・泉のグラデーションは作り置きします。動かすゴブリンはプレイヤーの近くの6体までです。
- 描画の解像度は devicePixelRatio を2までに抑え、30fpsを2秒続けて切ると自動で下げます。
- URLに `?debug=1` を付けると、左下にFPS・1フレームの処理時間・描画数・作った絵の数・保存している絵の量を出します。

## 拡張のしかた
- **場所**: `DATA.locations` に1件追加（`theme`・`field`・`eggTable`・`goblins`・`pool`）。図鑑ページも自動で増えます。
- **バトル**: `src/battles/<名前>.js` を足し、`DATA.battles` に1行追加。ゴブリンの `battles` で使うバトルと癖（`quirk`）を指定します。
  - バトルは `export default function (input, env)` を持ち、`update(dt)` / `draw(ctx, area, t, info)` / `result` / `timeUp()` を返します。
  - `input` は全バトル共通（連れているドラゴン・得意・ゴブリン・癖・有利かどうか）。結果は `great` / `good` / `fail` の3段階。
- **ドラゴンの系統**: `DATA.lineages` に骨組み（胴・首・しっぽの点列、脚、翼の根元、背骨、歩き方 `motion`）を1件追加。
- **パーツ**: `DATA.parts.<種類>` に1件追加。図鑑の種類は「系統・角・翼・しっぽ」の組み合わせです。
- **ゴブリン**: `DATA.goblins` に追加。`look.build`（slim / broad / stocky / robe）と `look.gear`（sack / club / drum / shield）で体格と装備が、`ai`（見回りの癖・歩く/走る速さ・視界）で行動が変わります。
- **卵・施設**: `DATA.eggs` / `DATA.facilities` に追加。
